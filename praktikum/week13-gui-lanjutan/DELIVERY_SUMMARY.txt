🎯 KEY FEATURES (Week 13 Specific)
═══════════════════════════════════════════════════════════════════════════════

1. ✅ TableView Component
   - TableView<Product> dengan 4 structured columns
   - Column headers: Code, Name, Price, Stock
   - PropertyValueFactory untuk automatic data binding
   - Selection model untuk row operations
   - Replaces ListView dari Week 12

2. ✅ Lambda Expression Implementation
   - btnAdd.setOnAction(e -> handleAddProduct())
   - btnDelete.setOnAction(e -> handleDeleteProduct())
   - btnRefresh.setOnAction(e -> loadData())
   - 3 event handlers menggunakan lambda syntax
   - Concise dan readable code

3. ✅ ObservableList Reactive Updates
   - ObservableList<Product> untuk data binding
   - TableView otomatis terupdate saat data berubah
   - Clear + addAll pattern untuk refresh
   - Reactive programming pattern

4. ✅ Confirmation Dialog
   - Delete operation dengan Alert(CONFIRMATION)
   - Dialog menampilkan nama produk
   - User dapat confirm atau cancel
   - Safe deletion workflow

5. ✅ Complete CRUD Operations
   - Create (Tambah Produk) dengan validation
   - Read (Load data dari database)
   - Update (Update stock/price)
   - Delete (Hapus Produk dengan confirmation)
   - Semua terintegrasi dengan TableView

6. ✅ Input Validation
   - Code tidak boleh kosong & max 20 char
   - Name tidak boleh kosong & max 100 char
   - Price harus > 0
   - Stock harus >= 0
   - Error messages untuk setiap validation

7. ✅ Database Integration
   - PostgreSQL dengan JDBC driver
   - Connection pooling & proper resource cleanup
   - PreparedStatement untuk SQL injection prevention
   - Full transaction support
